# Zimbabwe House Price Modelling

HDSC405 Deep Learning, University of Zimbabwe: mini research project.

**Research question:** Which features explain the asking prices of houses for sale in Zimbabwe, and how accurately can a model predict them?

## 1. Overview

This repository contains the full pipeline for the project:

1. **Collect** house listings (structured data, descriptions, photos) from [property.co.zw](https://www.property.co.zw/houses-for-sale).
2. **Clean and explore** the data.
3. **Model** asking prices: a linear regression baseline and a multimodal deep network (tabular features + house photos via a pretrained CNN + description text via a pretrained sentence transformer).
4. **Evaluate** on held-out data (RMSE, MAE, R²) with a fixed hold-out split and 5-fold cross-validation, check residuals and discuss limitations.

**Dataset:** 1,988 listings collected (5,872 photos); 1,964 houses after cleaning. The site reports about 2,600 houses for sale but stops serving results after 100 pages, so the 6,000 houses suggested in the brief were not obtainable (see section 9).

## 3. Setup

Requires Python 3.10+. No GPU is needed (everything runs on CPU).

```bash
pip install -r requirements.txt
```

The first run of `features.py` downloads two pretrained models (ResNet-50, about 100 MB, and all-MiniLM-L6-v2, about 90 MB).

## 4. How to reproduce the results

Run the steps in order from the repository root. The cleaned dataset and photos are already included, so you can skip step 1 and start at step 2.

### Step 1: data collection (optional, slow)

Each stage can be stopped (Ctrl+C) and restarted safely: finished work is not repeated.

```bash
python Crawler.py index --passes 1      # walk the results pages -> data/listings_index.csv
python Crawler.py details               # fetch each listing page -> data/details.jsonl
python Crawler.py images --per 3        # download up to 3 photos per listing -> images/
python Crawler.py build                 # join everything -> data/houses_raw.csv
```

Quick test: `python Crawler.py index --max-pages 2` and `python Crawler.py details --limit 5`.
If `parse_listing.py` is changed, run `python reparse.py` to re-parse the saved HTML without downloading again, then `python Crawler.py build`.

### Step 2: cleaning, exploration and baseline

```bash
python clean.py        # -> data/houses_clean.csv, data/cleaning_log.txt
python eda.py          # -> report/figures/
python baseline.py     # -> data/split.csv, results/baseline_*
```

### Step 3: multimodal model

```bash
python features.py             # -> data/features/ (about 15-40 min on CPU; --model resnet18 is faster)
python multimodal.py --quick   # fast test run
python multimodal.py           # -> results/ablation_*.csv, multimodal_*.png/json
```

### Responsible collection

- The crawler reads `robots.txt` first and stops if the paths are disallowed.
- It pauses 2 to 3.5 seconds between page requests (0.5 to 1.2 s for image files).
- It backs off on HTTP 429/5xx errors and stops after three consecutive 403 responses.
- Its User-Agent identifies it as a university coursework project and includes a contact email.
- Every record stores `collected_at` (UTC timestamp). Date of collection: _FILL IN START AND END DATES_.
- Raw HTML is saved in `data/raw/` so the data can be re-parsed without re-downloading.
- The data is used only for this coursework project and is not redistributed commercially.

## 6. Data cleaning and exploration

`clean.py` (full log in `data/cleaning_log.txt`):

- Removed duplicates: same listing ID, or identical description + price + suburb (13 listings).
- Removed 9 listings with no valid price. All remaining prices are in USD, so no conversion was needed.
- Removed 2 extreme price outliers (|robust z-score| > 4 on log price).
- Set implausible values to missing (floor size under 10 m² or over 5,000 m², land under 10 m² or over 200,000 m², more than 20 bedrooms or bathrooms).
- Missing numeric values are **not** imputed in `clean.py`; they are imputed with the training median inside each model pipeline (with missing indicators), so nothing leaks from the test set.
- Final dataset: **1,964 houses**.

Summary (cleaned data): median price USD 185,000 (mean 294,057; range 4,000 to 3,400,000). Missing: floor size 15%, amenities 20%, bathrooms 10.5%, land size 3%. The median asking price is about USD 460,000 in Harare North but 50,000 in Harare High Density. Correlations with log price: land size 0.70, floor size 0.54, bathrooms 0.51, number of amenities 0.42, bedrooms 0.37. Tables and plots are in `report/figures/`.

## 7. Models

All models predict **log price**.

- **Baseline:** linear regression on the tabular features (standardised numeric variables, missing indicators, one-hot region, suburb and property type).
- **Multimodal network** (PyTorch): three branches fused by a small head.
  - Tabular branch: preprocessed structured features.
  - Image branch: frozen ImageNet-pretrained ResNet-50 embedding, averaged over up to 3 photos, reduced with PCA (64 components).
  - Text branch: frozen all-MiniLM-L6-v2 sentence embedding of the description, reduced with PCA (32 components).
  - Training: AdamW, dropout 0.3, Huber loss, early stopping on a validation subset; 5 random seeds.
- Pretrained encoders are frozen because fewer than 2,000 houses would overfit a CNN or transformer trained from scratch. PCA and all preprocessing are fitted on training rows only.
- **Ablation:** tabular only, tabular + text, tabular + images, tabular + text + images.

## 8. Evaluation

One 80/20 hold-out split (1,571 train / 393 test, fixed seed, stored in `data/split.csv`) is used for every model, plus 5-fold cross-validation over all houses. Metrics: RMSE, MAE and R² on log price and on USD (back-transformed).

**Hold-out (neural networks: mean of 5 seeds)**

| Model | Log RMSE | Log MAE | Log R² | USD MAE | USD R² |
|---|---|---|---|---|---|
| Linear regression (baseline) | 0.438 | 0.282 | 0.819 | 89,788 | 0.590 |
| Network: tabular only | 0.422 | 0.271 | 0.831 | 82,973 | 0.620 |
| Network: tabular + text | 0.422 | 0.274 | 0.831 | 84,094 | 0.642 |
| Network: tabular + images | 0.415 | 0.261 | 0.837 | 82,307 | 0.635 |
| Network: tabular + text + images | **0.409** | **0.257** | **0.842** | **80,487** | **0.658** |

**5-fold cross-validation (mean over folds)**

| Model | Log RMSE | Log MAE | Log R² | USD MAE | USD R² |
|---|---|---|---|---|---|
| Linear regression (baseline) | 0.391 | 0.271 | 0.841 | 85,674 | 0.634 |
| Network: tabular only | 0.389 | 0.274 | 0.843 | 85,642 | 0.649 |
| Network: tabular + text | 0.384 | 0.273 | 0.847 | 84,680 | 0.653 |
| Network: tabular + images | 0.369 | 0.260 | 0.859 | 82,955 | 0.666 |
| Network: tabular + text + images | **0.367** | 0.261 | **0.860** | **81,995** | **0.677** |

**Findings:** the full multimodal model is best on every hold-out metric and nearly all cross-validation metrics, improving log R² by about 0.02 over the linear baseline. Photos contribute most; text descriptions add little beyond the structured fields. Differences between models are modest relative to fold-to-fold variation (sd of R² about 0.02). Residual plots: `results/baseline_residuals.png`, `results/multimodal_residuals.png`. Full tables: `results/ablation_holdout.csv`, `results/ablation_cv.csv`.

## 9. Limitations

- **Sample size:** only 1,964 houses were obtainable (the site lists about 2,600 and stops serving results after 100 pages), fewer than the 6,000 suggested. The sample is limited to what is advertised online and is concentrated in Harare.
- Asking prices are not sale prices, and the data is a single snapshot in time.
- Some fields (bathrooms, floor size, amenities, exact GPS) are missing for many listings and are entered by agents.
- The CNN and text encoders are pretrained and frozen; fine-tuning might extract more from the photos.
- USD-scale errors are dominated by a few very expensive houses, so log-scale metrics are more reliable.
- Differences between models are small relative to the noise from a 393-house test set.
